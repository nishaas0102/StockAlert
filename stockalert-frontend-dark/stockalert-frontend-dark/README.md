# StockAlert Frontend (Neon Dark Theme)
Plain HTML + CSS + JavaScript (no build step).

1. Start the Spring Boot backend (http://localhost:8080).
2. Open this folder in VS Code and install the "Live Server" extension.
3. Right-click index.html -> "Open with Live Server" (runs at http://127.0.0.1:5500).

The backend URL is the first line of js/app.js (const API).
